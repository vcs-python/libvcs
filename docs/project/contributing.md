# Contributing

As an open source project, libvcs accepts contributions through [GitHub].
The contributor guide — environment setup, the gates, tests, releasing, and
pull requests — now lives at [`.github/CONTRIBUTING.md`][contributing-file]
in the repository; prose conventions live at
[`.github/WRITING.md`][writing-file].

Ready to dive in? See the {ref}`Development Workflow <workflow>` page for a
day-to-day loop through the same commands.
